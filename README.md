# Tu mensaje deja huella
## Campaña de Prevención del Ciberbullying en Perú

**Juan Carlos Garibay Alarcón**

## 📋 Descripción

Landing page interactiva para la campaña de prevención del ciberbullying "Tu mensaje deja huella", dirigida a adolescentes peruanos de 12-17 años, padres y docentes.

## 🎯 Objetivo

Generar conciencia sobre las consecuencias del ciberbullying y fomentar la empatía digital entre estudiantes (12-17 años), padres y docentes en Perú.

## ✨ Características

- **5 secciones interactivas** con scroll narrativo
- **Diseño cinematográfico** con iluminación neón (cian/magenta)
- **Interactividades significativas**: simulador de chat, infografías animadas, efectos parallax
- **Contenido basado en datos reales** de Perú con enlaces verificables
- **Totalmente responsive** (mobile, tablet, desktop)

## 🚀 Cómo Usar

1. Abre `index.html` en tu navegador
2. O visita: https://stopciberbullying.site

## 💻 Tecnologías

- HTML5
- CSS3 (animaciones, gradientes, efectos neón)
- JavaScript (Vanilla JS, sin dependencias)
- Google Fonts (Poppins, Montserrat)

## 📊 Datos Incluidos

- **54%** de adolescentes peruanos ha sufrido ciberbullying
- **9 de cada 10** adolescentes creen que los riesgos digitales pueden tener consecuencias graves

## 🔗 Recursos Peruanos

- **Línea 100:** Teléfono 100 (24/7, MIMP)
- **SíseVe:** Sistema del Ministerio de Educación
- **Defensoría del Pueblo:** Recursos educativos
